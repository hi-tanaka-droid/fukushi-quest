# 福祉クエスト 3D

社会福祉原論Aの学習ゲーム。3Dの街を歩き、8か所で手がかりを集め、暮らしを複数の視点から考えます。各クエストは手がかり3枚・問い3つ、全24問です。

v4.1では「灯りのまつり」を目標に、12個の光のかけら、3種類の回転タイルパズル、コート・広場・空の色の変更を追加しました。歩いて見つけ、試してつなぎ、街の変化を楽しめます。

## 探検と寄り道

- **光のかけら12個**：近づくと収集。案内灯のランプが次の目印を示します。「あそび」の図鑑から、探したいかけらを選ぶこともできます。
- **光の回路3つ**：3×3、4×4、5×5のタイルを回し、左の入口から右の出口までつなぎます。ヒントもやり直しも無制限。教材の正誤判定とは別の寄り道です。
- **着替え・街づくり**：かけら4個・8個でコートの色、回路1つで風の飾りと夕暮れ、2つで星の飾り、3つで夜の街を選べます。何度でも変更でき、収集したものは消費しません。
- **まつり**：かけら12個・回路3つ・学び8か所がそろうと、探検メモから街に浮かぶ灯りの演出を始められます。人物や社会の状態を採点するものではありません。

Shiftまたは「小走り」で速く移動、Spaceまたは「ジャンプ」で跳べます。小走りボタンは切替式です。ジャンプをしなくても、かけらは集められます。音声の自動再生、戦闘、減点、課金はありません。

## 遊び方

1. 光の輪に近づいて「調べる」。または「旅の地図」から場所を選びます。
2. 3枚の手がかりを開き、問いに取り組みます。手がかりはいつでも読み返せます。
3. 各問の解説を確認すると進めます。3問を終えると街に灯りがともります。
4. 迷った問いは「復習」、これまでの解説は「まなびの書」に残ります。

移動：WASD／矢印キー／画面の方向ボタン。ドラッグで視点を回転、ホイールで距離を変更、Eで近くの相談を開きます。「？」から視点の回転と装飾の動きを止められます。

時間制限、残機、戦闘、ランキングはありません。街の灯りは学習の進捗で、人の価値や支援能力の点数ではありません。3Dを表示できない端末でも地図から同じ24問の学習内容と、あそび画面の3種類のパズルを利用できます。かけらの探索には3D表示が必要です。

## 教材の範囲

元スライド14本を確認し、出題に使う概念を限定しました。制度と権利の説明は公式資料と照合しています。事例・会話・街・計算練習用のデータは創作です。人物画・写真・QRコード・学生の記述は転載していません。

各問から元PDF名・ページと確認資料を開けます。採用／不採用の理由は [教材確認記録](docs/CONTENT_AUDIT.md) に記載しています。元PDFの照合用情報は [資料一覧](docs/SOURCE_MANIFEST.json) に収録しています。元PDFそのものは配信しません。

旧版の問題・豆知識は引き継いでいません。制度の金額、条件不明の統計比較、原因を一つに断定する説明等は出題対象外です。授業全体を網羅する試験対策集ではありません。

## 保存とオフライン

- 新しい記録は端末の `localStorage` の `fukushi_quest_v4` に保存します。旧版の `fukushi_quest_v2` は削除・変換しません。
- 解説を確認した問い、復習対象、進行中のクエスト、3D内の位置、動きの設定、かけら、パズルの途中の配置とクリア、見た目の選択を保存します。v4.0の学習記録は引き継ぎます。個人情報を入力する欄や外部送信はありません。
- 保存できない環境では案内を表示し、その画面を閉じるまでは遊べます。
- HTTPSまたはlocalhostで初回の保存が完了すると、ゲームをオフラインで利用できます。外部の公式資料は通信が必要です。
- キャッシュはアプリの配信範囲ごとに分離し、他のアプリのキャッシュを削除しません。

## 配信・ローカル起動

ビルドとnpm installは不要です。静的ファイル一式をそのままGitHub Pagesに配信できます。`/fukushi-quest/` のようなサブパスに対応しています。Three.jsは同梱しており、実行時にCDNへ接続しません。

ローカルではNode.js 20以上を用意し、このフォルダーで実行します。

```sh
node tools/serve.cjs
```

表示されたlocalhostのURLをブラウザで開きます。HTMLのダブルクリックによる `file://` 表示はES ModulesとService Workerに適さないため、HTTPサーバーで起動してください。

更新時には `sw.js` の `CACHE` の版番号を更新します。新しい資産一式の保存が成功してから切り替わり、次の読み込みで新しい版が表示されます。

## 検証

```sh
node --test tests/engine.test.cjs tests/offline.test.cjs tests/adventure.test.cjs
```

正答集合の全組合せ、復習、保存の復元・破損、移動の境界・衝突、オフライン資産とキャッシュの分離を検証します。画面での確認結果と未実施の範囲は [検証記録](docs/VALIDATION.md) を参照してください。

主なファイル：`content.js` は教材、`engine.js` は判定と保存形式、`app.js` は学習画面、`adventure.js` はパズルと報酬のルール、`adventure-ui.js` は探検メモ、`world.js` と `world-play.js` は3D空間、`sw.js` はオフライン処理です。
